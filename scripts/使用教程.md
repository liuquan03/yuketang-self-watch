# Yuketang 自助观看使用教程

`Yuketang 自助观看` 由 `liuquan03` 维护，用于辅助本人观看雨课堂视频，并在使用者明确操作后打开作业页。作业需要使用者本人作答和提交。

## 1. 准备环境

请先安装：

- Node.js 20 或更高版本
- Microsoft Edge 或 Google Chrome
- 本项目源码

在终端中检查 Node.js：

```bash
node -v
npm -v
```

## 2. 安装依赖

进入项目的 `scripts` 目录：

```bash
cd yuketang-self-watch/scripts
npm ci
```

## 3. 启动助手

在雨课堂中打开自己要学习的视频，复制浏览器地址栏中的完整 HTTPS 网址，然后执行：

```bash
npm start -- "这里替换成自己的雨课堂视频网址"
```

浏览器打开后：

1. 使用自己的雨课堂账号扫码登录。
2. 保持启动脚本的终端窗口运行。
3. 登录状态会保存在本机的 `scripts/user-data/` 目录。

## 4. 控制命令

保持第一个终端运行，再打开第二个终端，进入 `scripts` 目录后使用以下命令：

```bash
# 查看运行状态
npm run status

# 确认本人仍在观看
npm run presence

# 打开目录中的下一个作业
npm run homework

# 完成作业后返回之前的视频
npm run study

# 暂停视频
node ctl.js pause

# 播放视频
node ctl.js play

# 进入目录中的下一个视频
node ctl.js next

# 停止助手
node ctl.js stop
```

`npm run homework` 只会打开目录中明确标注为“作业”的下一项。打开后，脚本会停止自动操作，使用者需要亲自选择答案并提交。

## 5. 重新启动

### macOS 或 Linux

```bash
./restart.sh "自己的雨课堂视频网址"
```

如果提示没有执行权限：

```bash
chmod +x restart.sh
./restart.sh "自己的雨课堂视频网址"
```

### Windows PowerShell

```powershell
npm start -- "自己的雨课堂视频网址"
```

## 6. 更换登录账号

在脚本打开的浏览器窗口中退出当前账号，然后使用新账号重新扫码登录。

## 7. 分发前的安全检查

把项目发给其他人之前，不要包含：

```text
scripts/user-data/
scripts/control-token
scripts/node_modules/
```

- `user-data/` 保存当前用户的登录状态，不应与他人共享。
- `control-token` 是当前运行实例的本地控制令牌。
- `node_modules/` 可以由使用者通过 `npm ci` 重新安装，无需分发。
- 每位使用者都应使用独立项目副本并亲自扫码登录。
