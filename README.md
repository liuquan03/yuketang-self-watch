# Yuketang 自助观看

`Yuketang 自助观看` 是由 `liuquan03` 维护的雨课堂学习辅助工具，用于本人正常观看课程时减少重复操作。当前提供：

- 2x 播放与暂停后续播；
- 自动处理“继续观看 / 我知道了”等固定提示；
- 视频自然结束后，只进入目录中明确标注为“视频”的下一项；
- 发现题目立即暂停，由本人在页面中完成；
- 经本人明确操作后打开目录中的作业，并在手动完成后返回视频；
- 每 2000 分钟重新确认本人仍在观看。

安全模式不提供答题、作业提交、任意页面脚本执行、截图、DOM 导出或任意网址跳转接口。

## 安装与启动

要求 Node.js 20 或更高版本，并已安装 Edge 或 Chrome。

```bash
cd scripts
npm ci
npm start
```

首次启动会打开浏览器，请本人扫码登录。登录态只保存在 `scripts/user-data/`，控制令牌保存在权限为 `0600` 的 `scripts/control-token`；两者均不应提交到 Git。

默认启动页为雨课堂首页。如需直接打开某个视频，可把完整 HTTPS 地址作为 `npm start -- '<网址>'` 参数传入。

## 本地控制

控制接口仅监听 `127.0.0.1:7862`，并要求启动时随机生成的令牌。使用随附命令，无须手工读取令牌：

```bash
npm run status
npm run presence
npm run homework
npm run study
node ctl.js play
node ctl.js pause
node ctl.js next
node ctl.js stop
```

`npm run homework` 只会打开目录中明确标注为“作业”的下一项，然后停止自动操作。请你在浏览器中亲自作答和提交；完成后运行 `npm run study` 返回之前的视频。

只有本人确认仍在观看时才运行 `npm run presence`。在场确认过期后，程序会暂停视频，也不会进入下一节。

## 安全边界

- 起始页和新标签页必须是 `https://yuketang.cn` 或其子域名；其他页面不会成为控制目标。
- 弹题只暂停，不识别答案、不代点、不提交。
- 作业模式只负责打开作业页，不选答案、不点提交。
- 下一节必须被页面明确标注为“视频”；无法确认时停止等待本人处理。
- 本项目不会快进或主动修改进度，且每轮巡检都会把播放速度恢复为 1x。
